# JavaScript Fundamentals

A collection of JavaScript practice programs covering core
JavaScript concepts while learning Full Stack Development.

## Topics Covered

- Variables and Data Types
- Operators
- Conditional Statements
- Loops
- Functions
- Arrow Functions
- Arrays
- DOM Manipulation
- Basic Problem Solving

## Structure

datatype.html     → JavaScript data types
operator.html     → Operators
condition.html    → Conditional statements
loop.html         → Loops and arrays
function.html     → Functions and arrow functions
hello.html        → JavaScript basics
